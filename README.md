# Contrôle optimal

Supports du cours de **contrôle optimal** de l'[ENSEEIHT](https://www.enseeiht.fr/),
département **Sciences du numérique**.

Le cours porte sur la modélisation et l'optimisation de systèmes dynamiques
commandés : systèmes contrôlés, formulations de problèmes de contrôle optimal,
conditions nécessaires d'optimalité (principe du maximum de Pontryagin) et
méthodes numériques (tir indirect, méthodes directes). Les travaux pratiques
sont réalisés en [Julia](https://julialang.org).

Les supports (polycopié, travaux pratiques, sujets d'examen) seront ajoutés
progressivement dans ce dépôt.

## Cloner et mettre à jour le dépôt

Il est recommandé de cloner le dépôt plutôt que de télécharger les fichiers
un par un.

Pour récupérer le dépôt la première fois :

```bash
git clone https://github.com/ocourses/controle-optimal.git
cd controle-optimal
```

Pour récupérer les mises à jour ensuite :

```bash
cd controle-optimal
git pull
```

Si vous modifiez un notebook, faites-en de préférence une copie personnelle
avant de travailler dessus : vous pourrez ainsi récupérer les futures versions
sans risquer de conflit avec vos modifications.
